# 🔥 搜狐热帖助手

每天帮你生成有营养的原创短帖子，复制后搬运到搜狐新闻发布。

## 使用方法

1. 打开网址: `https://klnm2037453337-sudo.github.io/sohuxw/`
2. 选择风格（闲聊 / 快讯）
3. 点「生成一篇 →」（会打开一个新标签页）
4. 在新标签页点绿色 **Run workflow** 按钮
5. 关闭标签页，回到网页等 15-60 秒，新帖子自动出现
6. 点「复制」→ 去搜狐新闻发布

## 技术栈
- GitHub Pages（静态托管）
- GitHub Actions（云端执行）
- DeepSeek API 生成文字
- Unsplash API 搜索配图
