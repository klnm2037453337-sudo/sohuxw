# 搜狐热帖助手 — 内容与视觉重设计

## 概述

重新设计生成内容类型（从 2 种扩展到 12 种，分 3 大类），新增字数选择、链接输入、实时预览功能。视觉上采用云海草坡场景 + 淡彩水墨风格。

## 视觉设计

### 整体风格：云海草坡 + 淡彩水墨

**背景场景**（CSS 绘制）：
- 天空：蓝白渐变，太阳光晕（径向渐变），多层白云（模糊椭圆）
- 中景：草坡岛屿（CSS 椭圆 + 渐变），小木屋（CSS 三角形屋顶 + 矩形屋体），电线杆 + 电线
- 氛围：日出柔光，温暖金色光晕

**面板风格**：
- 半透明白色背景 `rgba(255,255,255,0.5)`
- 毛玻璃模糊 `backdrop-filter: blur(24px)`
- 圆角 20px，边框 `rgba(255,255,255,0.55)`
- 柔和阴影

**配色**：
- 主文字：`#5c4a3a`（深棕）
- 副文字：`#a08870` / `#8b7355`（中棕）
- 强调选中：`rgba(180,140,100,0.3)` + 边框 `#b48c64`（赭石）
- 按钮渐变：`#b48c64` → `#8b6914`
- 未选中：`rgba(255,255,255,0.3)` 半透明

**字体**：系统无衬线（中文用 system-ui），字间距加大（letter-spacing: 1-2px）

### 交互细节

1. **分类切换**：点击分类标签，切换下方子类型 pills
2. **子类型选择**：点击 pill 选中（边框高亮 + 背景加深）
3. **字数选择**：点击 pill 选中（背景变为赭石色）
4. **Hover 提示**：鼠标悬停子类型 pill，上方弹出描述文字气泡
5. **链接输入**：选填，placeholder 提示"粘贴新闻链接（选填，留空则AI自由选题）"
6. **生成按钮**：点击后触发 GitHub Actions workflow_dispatch
7. **右侧预览**：生成前显示占位引导，生成完成后显示帖子内容 + 复制按钮
8. **底部滚动栏**：卡片支持触摸横向滑动（scroll-snap），左右 ◂ ▸ 按钮点击滚动一页
9. **缩略卡片点击**：弹窗 / 展开查看完整内容

## 后端改动

### generate.yml 新增参数

```yaml
inputs:
  genre:        # 内容类型，如 "时事短评"
    required: true
    type: string
  word_count:   # 字数档位，如 "中"
    required: true
    type: string
  source_url:   # 参考链接（可选）
    required: false
    type: string
```

### generate.py 改动

- 接收 `--genre`、`--word-count`、`--source-url` 参数
- 如果提供 `source_url`，用 trafilatura 抓取网页正文作为 AI 参考上下文
- 更新 System Prompt：根据 genre + word_count 精确控制输出
- trafilatura 安装：`pip install trafilatura`

### script.js 改动

- 收集选中的 category、sub-type、word_count、url
- 将这些参数传给 workflow dispatch API
- 轮询逻辑保持不变

## 约束

- 页面须能在 GitHub Pages 上以纯静态方式运行
- 图片场景用纯 CSS 实现（不依赖外部图片资源）
- DeepSeek API 调用保持在 60 秒超时内完成
- trafilatura 抓取需处理超时和抓取失败的情况
